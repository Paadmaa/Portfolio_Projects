# 📈 Marketing Analytics Dashboard

## 📌 Project Overview
This project analyzes multi-channel marketing performance across products, seasons, and audience engagement metrics.  

It transforms raw campaign data into **actionable insights** using interactive visualizations and key performance indicators (KPIs).

The goal: **Identify high-performing products, detect underperformers, optimize seasonal strategies, and improve conversion outcomes.**

---

## 🎯 Objectives
- **Evaluate campaign performance** using views, clicks, likes, and conversion rates.
- **Spot high-ROI products** for upsell opportunities.
- **Identify weak performers** and propose targeted interventions.
- **Analyze seasonal and monthly trends** to optimize marketing spend.
- **Incorporate customer sentiment** to align marketing with brand perception.

---

## 🗂 Dataset Highlights
**Source:** Marketing performance PDF (converted and analyzed)  
**Timeframe:** Jan–Dec (multi-year trend patterns visible)
