# 🛒 Reliance SMART – Sales Performance Dashboard

## 📌 Project Overview
This dashboard delivers a **multi‑dimensional view of Reliance SMART’s retail performance**, covering **transactions, revenue, profit, returns, geography, and product brand mix**.  
It allows decision‑makers to:
- Spot revenue concentration by geography & brand.
- Benchmark KPIs against targets.
- Pinpoint improvement opportunities in low‑performing markets or product lines.

---

## 🎯 Key Business Objectives
1. Track **transactions, revenue, profit, and return rates** at national, state, and brand level.
2. Compare current month KPIs against **previous month performance** and set goals.
3. Analyze **regional sales patterns** to optimize distribution.
4. Identify **top‑ and low‑performing brands** to guide inventory and promotions.
