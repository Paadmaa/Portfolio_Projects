# ⚡ Electric Vehicle Population Analysis | Power BI Dashboard

## 🚀 Project Overview  
This project presents a comprehensive analysis of electric vehicle (EV) adoption trends across the United States using Power BI. It explores vehicle types, manufacturers, model years, and eligibility for clean alternative fuel incentives. The dashboard enables stakeholders to understand market dynamics and identify growth opportunities in the EV sector.

---

## 📂 Dataset Summary  
The dataset includes over 150,000 EV records with attributes such as:

| Column                     | Description                                      |
|---------------------------|--------------------------------------------------|
| Vehicle Type              | BEV (Battery Electric Vehicle) or PHEV (Plug-in Hybrid) |
| Make & Model              | Manufacturer and specific vehicle model         |
| Model Year                | Year of manufacture                             |
| Electric Range            | Average distance per charge                     |
| State & City              | Registration location                           |
| Electric Utility          | Associated utility provider                     |
| CAFV Eligibility          | Clean Alternative Fuel Vehicle program status   |

## 📌 Dashboard Features  
The Power BI dashboard includes:

1. **Filter Panel** – Dynamic filters for city, utility, vehicle type  
2. **Summary KPIs** – Total vehicles, range, and type breakdown  
3. **Model Year Trends** – EV adoption over time  
4. **Make & Model Analysis** – Popular manufacturers and models  
5. **CAFV Eligibility** – Incentive program participation  
6. **Geographic Distribution** – Vehicle counts by state

---

## 🧠 Analytical Highlights  
- **DAX Measures** – Used to calculate EV type percentages and average range  
- **Interactive Visuals** – Slicers and drill-downs for user-driven exploration  
- **Trend Analysis** – Identifies growth periods and manufacturer shifts  
- **Policy Insights** – Evaluates impact of CAFV eligibility on adoption
