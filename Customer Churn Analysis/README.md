# 📉 Customer Churn Analysis | Power BI Dashboard

## 🚀 Overview  
This project explores customer churn dynamics using an interactive Power BI dashboard. The goal is to uncover patterns behind customer attrition and provide actionable insights to improve retention strategies.  

Whether you're a business leader or data enthusiast, this dashboard offers a clear lens into churn risk factors across demographics, services, and account behaviors.

---

## 📂 Dataset Summary  
The dataset includes customer profiles, subscription details, and churn status. Key features:

| Column                | Description                                  |
|----------------------|----------------------------------------------|
| Customer ID          | Unique identifier                            |
| Subscription Type    | Monthly, Yearly, Premium                     |
| Tenure (Months)      | Duration of subscription                     |
| Monthly & Total Charges | Billing details                         |
| Contract Type        | Month-to-Month, One-Year, Two-Year           |
| Payment Method       | Credit Card, Bank Transfer, PayPal, etc.     |
| Support Calls        | Number of customer service interactions      |
| Churn Status         | Yes / No                                     |

## 📌 Dashboard Walkthrough  
The Power BI dashboard is organized into five key sections:

1. **Summary View** – High-level KPIs and churn overview  
2. **Demographics** – Gender, age, and location-based churn analysis  
3. **Account Info** – Contract types, payment methods, and tenure impact  
4. **Service Usage** – Churn trends by internet and streaming services  
5. **Churn Distribution** – Root causes and segment-level breakdowns  

---

## 🧠 Analytical Techniques  
- **DAX Measures** – Custom KPIs for churn rate, tenure, and revenue impact  
- **Interactive Filters** – Slicers for dynamic exploration  
- **Drill-through Pages** – Deep dives into customer segments  
- **ML Insights** – Predictive modeling for churn risk

---

## 💡 Business Recommendations  
- Prioritize retention for **Month-to-Month** customers  
- Offer **long-term contract incentives**  
- Improve **customer support responsiveness**  
- Use **personalized offers** based on service usage  
- Monitor **high-risk payment methods** like Mailed Check
