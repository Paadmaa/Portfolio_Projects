# 🌎 **Region Wise 360: Multi-Year Sales Intelligence Dashboard**

## 📌 Project Overview  
This Power BI dashboard delivers a **multi-year, region-wise analysis** of sales, profit, and quantity across U.S. states from 2021 to 2024. It empowers stakeholders to compare current vs previous year performance, identify regional growth patterns, and uncover strategic opportunities for sales optimization.

---

## 🎯 Business Objectives
- Compare **Current Year (CY)** vs **Previous Year (PY)** metrics across regions.
- Track **YoY growth** in sales, profit, and quantity.
- Visualize **state-level performance** using an interactive map.
- Enable **dynamic filtering** by year and measure (Sales, Profit, Quantity).
- Support **regional strategy planning** with granular insights.

## 📈 Dashboard Features
- **Interactive Map**: Sales by state with dynamic tooltips.
- **Region Cards**: CY vs PY metrics with YoY % change.
- **Measure Selector**: Toggle between Sales, Profit, and Quantity.
- **Year Filter**: View performance for 2021–2024.
- **Clean Layout**: Intuitive design for executive-level consumption.

---

## 🛠 Tools & Technologies
- **Power BI**: Dashboard design and interactivity  
- **DAX**: Year-over-year calculations and dynamic measures  
- **Power Query**: Data transformation and model setup  
- **Excel**: Source data preparation (Sales Overview Data.xlsx)
